# Дизайн-система «Груша»: светлый футуризм

Сайт салона красоты «Груша» (Химки), сделан 26–27.09.2026.

- Живая версия: https://lilbunnych.github.io/Portfolio/pitch/grusha/
- Исходники: `~/Portfolio/pitch/grusha-src/` (ниже пути к файлам указаны относительно `src/`)

Этот файл описывает визуальный язык, компоненты, эффекты и найденные грабли, чтобы повторить стиль в новом проекте. В конце есть готовый промпт.

---

## 1. Стек

- Vite + React 19 + TypeScript
- Tailwind CSS v4: токены в `@theme`, утилиты через `@utility`
- three.js через `@react-three/fiber` и `@react-three/drei` (только первый экран, грузится лениво)
- Motion (`motion/react`) для анимаций, Lenis для плавного скролла
- Иконки `lucide-react`
- Шрифты локально через fontsource: `@fontsource-variable/unbounded`, `@fontsource-variable/manrope`, `@fontsource-variable/jetbrains-mono`, а также `@fontsource/unbounded` (нужен `.woff` для 3D-текста)
- Vite `base: './'`, сборка в соседнюю папку для GitHub Pages

## 2. Визуальный язык

**Настроение:** светлый футуризм. Мятный фон с живым волнистым градиентом, матовые стеклянные панели с тонкой светлой кромкой, широкий гротеск в заголовках, один кислотный акцент.

### Палитра

| Токен | Цвет | Где используется |
|---|---|---|
| `background` | `#eaf3e6` | фон страницы (мята) |
| `foreground` | `#0f2417` | текст, тёмные кнопки, тёмные панели |
| `muted` | `#4a5f50` | вторичный текст |
| `leaf` | `#2f7a37` | иконки, ссылки, фокус |
| `lime` | `#c8f25a` | акцент, только как заливка под тёмным текстом: бейдж «хит», активный фильтр, звёзды на тёмном |
| `mint` | `#d6ead0` | подложки картинок |
| `card` | `#f6faf3` | запасной сплошной фон для стекла |

Правила:
- Акцент один, лайм. Лаймовым текстом на светлом фоне не пишем, контраста не хватит.
- Тема одна, светлая. Тёмные только отдельные панели (`glass-dark`): рейтинг, «Не нашли ответ?», подвал.

### Шрифты

- **Unbounded** (широкий, футуристичный): заголовки секций, всё `uppercase`, `tracking-[-0.02em]`, `leading-[1.02]`, размер `clamp(2.1rem, 5.2vw, 4.6rem)`.
- **Manrope**: основной текст.
- **JetBrains Mono**: только короткие метки из одного слова («ХИТ», «МАНИКЮР»). В ценах, телефонах и фразах моноширинный шрифт не использовать: пробелы в нём шириной с цифру, и «6 500 ₽» выглядит как «6  500  ₽».
- Цифры: `tabular-nums`.

### Формы и материалы

- Радиусы: кнопки и чипы — капсулы (`rounded-full`), панели — 28px, внутренние плитки — 20px.
- Стекло (`index.css`):

```css
@utility glass {
  background: linear-gradient(135deg, rgb(255 255 255 / .62), rgb(255 255 255 / .32));
  border: 1px solid rgb(255 255 255 / .7);
  box-shadow: inset 0 1px 0 rgb(255 255 255 / .9), 0 24px 60px -34px rgb(15 36 23 / .45);
  backdrop-filter: blur(22px) saturate(160%);
  -webkit-backdrop-filter: blur(22px) saturate(160%);
  @media (prefers-reduced-transparency: reduce) { background: var(--color-card); backdrop-filter: none; }
}
@utility glass-dark {
  background: linear-gradient(135deg, rgb(15 36 23 / .92), rgb(15 36 23 / .82));
  border: 1px solid rgb(200 242 90 / .18);
  box-shadow: inset 0 1px 0 rgb(255 255 255 / .08), 0 24px 60px -30px rgb(15 36 23 / .6);
  backdrop-filter: blur(18px);
}
```

- Тени всегда тонированы в цвет `foreground`, чисто чёрных нет.
- Основная кнопка: тёмная капсула `bg-foreground text-background h-12 px-7`, при наведении по ней проходит лаймовый блик (утилита `sheen`). Вторичная кнопка: прозрачная капсула с рамкой `border-foreground/20`.
- Живые статусы («Открыто до 21:00») отмечаются пульсирующей точкой (`live-dot`), только для реального состояния.
- `text-wrap: balance` для заголовков и кнопок, `text-wrap: pretty` для абзацев.

## 3. Первый экран: стеклянная груша (WebGL)

Файл `three/PearScene.tsx`. Холст на весь экран, лениво грузится через `React.lazy`. Рендер останавливается (`frameloop="never"`), когда экран уходит из вида.

Слои от дальнего к ближнему:

1. **Фон** — шейдер с волнистым градиентом на весь экран: domain-warp из simplex-шума, низкая частота (`p * 0.55`), медленное время (`uTime * 0.045`). Цвета идут от молочного `#f1f7ec` через мятный к сочному зелёному `#85c273`. Зона под текстом слева светлее, сверху лёгкое зерно против полос.
2. **Надпись «ГРУША»** — `drei <Text>` шрифтом Unbounded 800 (`.woff`, импорт через `?url`), `z = -2.2`, ширина около 92% экрана. Надпись стоит за грушей, и стекло её преломляет. Это главный вау-эффект.
3. **Орбиты** — два тонких тора (`0.006`) тёмно-зелёного цвета и лаймовый «спутник», медленно вращаются. Они непрозрачные, поэтому тоже видны сквозь стекло.
4. **Груша** — `LatheGeometry` по сплайну профиля плюс деформации:
   - слегка овальное сечение, два очень мягких «ряби» по кожуре;
   - бочок смещён, шейка наклонена в другую сторону;
   - ямки на дне и у хвостика;
   - шов сварен через `mergeVertices`, поэтому нормали гладкие;
   - vertex colors: желтоватый низ, более зелёные плечи, еле заметный румянец.

   Хвостик — сужающийся `TubeGeometry`, лист — `ExtrudeGeometry`, изогнутый по жилке.

Материал груши (нативное стекло three.js, без `MeshTransmissionMaterial`):

```tsx
<meshPhysicalMaterial vertexColors transmission={1} thickness={0.35} roughness={0.015} ior={1.3}
  dispersion={4} clearcoat={1} clearcoatRoughness={0.02} iridescence={0.2} iridescenceIOR={1.3}
  iridescenceThicknessRange={[150, 420]} attenuationColor="#e4f2c6" attenuationDistance={6} envMapIntensity={0.9} />
```

Свет: `<Environment>` с тёмным фоном `#1d3325` и несколькими узкими `Lightformer`-полосами. Блики получаются чёткими штрихами и не заливают стекло молоком. На `<Canvas>` стоит `flat` (без тонмаппинга).

Движение: груша левитирует (`sin(t*0.9)*0.1`) и поворачивается то в одну, то в другую сторону (`sin(t*0.42)*1.35 + sin(t*0.17)*0.5`), наклон идёт в противофазе. Лист трепещет отдельно, есть лёгкий параллакс от курсора. При `prefers-reduced-motion` амплитуда 35%.

Раскладка: груша привязана к пустому div-«якорю» в DOM. `ResizeObserver` переводит его прямоугольник в мировые координаты, так что вёрстка управляет положением 3D. Масштаб подобран так, чтобы груша вместе с листом влезала в якорь и не заходила под навигацию.

Под грушей две панели: стеклянная (h1 «Салон красоты в Химках», короткий текст, «Записаться» и «Цены») и тёмная (рейтинг и статус «открыто сейчас» по московскому времени). На телефоне тёмная панель схлопывается в одну строку внутри стеклянной.

## 4. Компоненты

- **Навигация** (`components/Nav.tsx`): стеклянная капсула `fixed top-4`, логотип Unbounded слева, ссылки по центру, активный раздел подсвечен «таблеткой» с `layoutId`, справа телефон и «Записаться» (со счётчиком выбранных услуг). После скролла фон становится плотным `bg-[#f3f8f0]/95`. На телефоне бургер открывает полноэкранное меню с крупными пунктами Unbounded.
- **Нижняя панель на телефоне:** «Позвонить» и «Записаться» появляются после 500px скролла.
- **Цитата владельца:** крупный текст, слова подсвечиваются по мере прокрутки. Заглушка: «Здесь будут ваши слова, которые вы бы хотели сказать клиенту о вашем салоне красоты», рядом фото интерьера.
- **Услуги с фильтрами:**
  - чипы направлений, первый — «Популярное» с иконкой огня (активный — лаймовый);
  - ряд ценовых диапазонов и поиск;
  - группы — стеклянные карточки по 6 строк с кнопкой «Ещё N»;
  - у популярных позиций лаймовый бейдж «хит»;
  - строка: название, цена справа, круглая кнопка «+» (добавить в запись), всё выровнено по центру;
  - на десктопе две стопки, сбалансированные по числу строк.
- **Галерея 2D** (`components/Gallery2D.tsx`): лента на нативном горизонтальном скролле со snap. Эффект:

```tsx
const { scrollX } = useScroll({ container: strip })
const skew = useTransform(useSpring(useVelocity(scrollX), { stiffness: 300, damping: 40 }),
  [-2400, 0, 2400], [9, 0, -9], { clamp: true })          // карточки наклоняются от скорости, как колода
// внутри карточки: фото шире рамки на 30% и сдвигается по позиции на экране (параллакс),
// карточка чуть увеличивается к центру
const x = useTransform(scrollXProgress, [0, 1], ['-14%', '14%'])
const scale = useTransform(scrollXProgress, [0, .5, 1], [.9, 1, .9])
```

  По тапу фото открывается в лайтбоксе. Подпись — плашка внизу карточки, при наведении приподнимается.
- **Мастера:** стеклянные строки с лаймовым кругом-инициалом, ролью и кнопкой «Записаться ↗», рядом сетка фото интерьера.
- **Отзывы:**
  - тёмная панель с рейтингом, который считается вверх;
  - блок «О чём пишут чаще всего» — чипы с числом отзывов, без процентов;
  - горизонтальная лента карточек, цитата до 3 строк и «Читать полностью»;
  - вкладка с живым виджетом.
- **Перед визитом (FAQ):** аккордеон из стеклянных карточек, заголовки Unbounded, рядом тёмная панель «Не нашли ответ?» с лаймовой кнопкой телефона.
- **Как нас найти:** статус «открыто», адрес, телефон, «Записаться» и «Маршрут», справа карта.
- **Онлайн-запись** (`components/Booking.tsx`): боковая панель с пружинным выездом, 4 шага (услуги, мастер, время, контакты), прогресс-полоски, валидация, итог с файлом `.ics`.
- **Подвал:** тёмная панель, большой логотип.

## 5. Анимации текста при скролле (`components/TextFx.tsx`)

- `SplitReveal` — слова заголовка выезжают из-под маски снизу с лёгким поворотом (stagger 0.07, ease `[0.16, 1, 0.3, 1]`). Отслеживается сам заголовок, а не спрятанные слова.
- `ScrollHighlight` — абзац загорается по словам (прозрачность от 0.14 до 1) по мере прокрутки.
- `CountUp` — числа считаются вверх при появлении.
- `Reveal` — блоки проявляются с подъёмом и снятием размытия.

Всё отключается при `prefers-reduced-motion`.

## 6. Типограф (`lib/typo.ts`)

Функция `typo()` и `watchTypography(root)`: MutationObserver проходит по всем текстовым узлам. Неразрывные пробелы ставятся:
- после слов из 1–2 букв и предлогов (для, без, под, над, при, про);
- перед «ли», «же», «бы»;
- в разрядах чисел, перед единицами (₽, м, лет, %), в датах («24 мая»).

Неразрывный дефис ставится внутри слов («тест-прядь») и в телефоне. Для анимированных заголовков `typo()` вызывается до разбиения на слова, иначе короткое слово окажется в отдельном блоке и сможет оторваться.

## 7. Грабли (обязательно учитывать)

1. **Шейдеры за стеклом:** `ShaderMaterial` должен отдавать линейный цвет (`pow(col, vec3(2.2))`) и заканчиваться `#include <colorspace_fragment>`. Иначе transmission видит цвета высветленными, и стекло выглядит молочным.
2. **Толщина стекла:** при большом `thickness` (больше ~0.5 при масштабе ~1) груша работает как лупа и размывает фон в сплошной цвет. Рабочие значения: `thickness 0.35`, `ior 1.3`.
3. **Тонмаппинг** ACES по умолчанию обесцвечивает стекло. Нужен `flat` на Canvas и тёмное окружение с узкими полосами света.
4. **CSS 3D в Safari:** Playwright WebKit (и headless, и оконный) рисует CSS-перспективу плоской, поэтому CSS-3D нельзя проверить под Safari. 3D делать на WebGL.
5. **CSS-колонки (`columns-2`) со стеклом** в WebKit не рисуют вторую колонку. Раскладку считать скриптом (две стопки).
6. **Утилита `glass`** задаёт shorthand `background`, и `bg-*` класс её не перекрывает. Для плотного состояния нужен отдельный набор классов.
7. **Маска и IntersectionObserver:** элемент, спрятанный под `overflow:hidden`, наблюдатель не видит. `whileInView` вешать на родителя и передавать анимацию через `variants`.
8. **Canvas не размонтировать при скролле:** иначе теряется WebGL-контекст и картинки пропадают. Останавливать через `frameloop`.
9. **Тесты:** `aria-label` у заголовка совпадал с `aria-label` региона, и селектор попадал не туда. Уточнять `[role=region]`.
10. **Моноширинный шрифт** растягивает пробелы. В ценах, телефонах и фразах использовать `tabular-nums` обычного шрифта.

## 8. Что пользователь отклонил

- Навигацию из «цветущих деревьев» (SVG-деревья вместо ссылок). Нужна обычная понятная навигация.
- Hero-шаблон «Minimalist Hero» с 21st.dev (портрет в круге и огромные слова справа).
- 3D-карусели на WebGL: вогнутую («края выходят из экрана») и выпуклую. Лучше 2D с эффектом.
- Выдуманный маркетинговый текст («кофе, пока работает краситель» и т. п.). Лучше цитата-заглушка в кавычках для владельца.
- Упоминания источника данных («фото и отзывы с Яндекс Карт»).
- Проценты в отзывах. Лучше темы с числом отзывов.
- Рваные переносы («1 / 000 ₽») и лишние пробелы в элементах.

## 9. Промпт для нового проекта

> Сделай сайт в стиле «светлый футуризм», как у салона «Груша» (~/Portfolio/_snippets/design-grusha.md).
> Стек: Vite, React, TypeScript, Tailwind v4, Motion, Lenis, react-three-fiber только для первого экрана.
> Фон страницы мятный `#eaf3e6`, текст `#0f2417`, единственный акцент — лайм `#c8f25a` как заливка под тёмным текстом.
> Заголовки: Unbounded, капслок, крупно. Текст: Manrope. Моноширинный только для коротких меток.
> Панели — матовое стекло с белой кромкой и радиусом 28px, кнопки — капсулы, основная кнопка тёмная с лаймовым бликом при наведении.
> Первый экран: на фоне медленного волнистого мятно-зелёного градиента (WebGL-шейдер) по центру стеклянный 3D-объект, который левитирует и поворачивается туда-обратно. За ним огромное слово-логотип, которое преломляется в стекле, вокруг тонкие орбиты. Внизу стеклянная панель с h1, коротким текстом и CTA и тёмная панель с рейтингом и статусом «открыто сейчас». Объект не должен заходить под навигацию.
> Навигация обычная: стеклянная капсула сверху, активный раздел подсвечен, на телефоне полноэкранное меню и нижняя панель «Позвонить / Записаться».
> Анимации текста при скролле: заголовки по словам из-под маски, цитата подсвечивается по словам, числа считаются вверх.
> Галерея — 2D-лента со snap, карточки наклоняются от скорости прокрутки, фото с параллаксом внутри.
> Каталог с фильтрами, один из них «Популярное» с бейджем «хит», фильтр по цене, поиск, карточки в две сбалансированные стопки.
> Русская типографика без рваных переносов (неразрывные пробелы после предлогов, в числах и перед ₽).
> Никакого выдуманного маркетингового текста: где нужны слова владельца, ставь заглушку в кавычках.
> Проверяй в WebKit (Safari) на телефоне и десктопе.
