# Tenth Demo — Understory

An editorial long read for a fictional magazine, "Understory". Story, people and quotes are invented.

## Stack

- One self-contained `index.html`: plain HTML, CSS and vanilla JavaScript
- Fonts: EB Garamond (text), Instrument Sans (UI)

## Features

- Reading progress bar and estimated reading time
- Sticky contents list that highlights the current section
- Footnote popovers with numbered notes at the end
- Three reading themes (paper, sepia, night) and adjustable text size, remembered per browser
- Drop cap, pull quote, wide figures, "copy link" button

## Run

Open `index.html` or serve the folder with any static server.
